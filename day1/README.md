# Day 01 – Student Placement Management System

## Objective
Designed the data model for a Student Placement Management System and practiced SOQL queries.

## Custom Objects
- Student__c
- Company__c
- Job__c
- Application__c

## Relationships
- Student → Application (Lookup)
- Job → Application (Lookup)
- Company → Job (Lookup)

## SOQL Topics Covered
- WHERE Clause
- ORDER BY + LIMIT
- Relationship Query
- Aggregate Query
- Comparison Operators

## Learning Outcome
- Created custom objects and fields
- Built lookup relationships
- Practiced SOQL queries
- Understood Salesforce data modeling
