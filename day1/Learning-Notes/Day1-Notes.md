# Learning Notes – Sprint 01

## Date
Day 1 – Salesforce Developer Bridge Program

## Topics Learned

### Salesforce Data Modeling
- Created custom objects:
  - Student
  - Company
  - Job
  - Application
- Learned how to create custom fields.
- Understood Lookup Relationships between objects.

### SOQL
Practiced writing different types of SOQL queries:
- WHERE Clause
- ORDER BY with LIMIT
- Relationship Query
- Aggregate Query using COUNT()
- Comparison Operators

### Apex Triggers
- Learned the difference between Before and After Triggers.
- Created a Before Insert Trigger.
- Used a Trigger Handler to separate business logic.
- Prevented duplicate job applications.

### Lightning Web Components (LWC)
- Created an LWC component.
- Used @wire to retrieve student records.
- Displayed data using lightning-card.
- Added the component to the Lightning Home Page.

## Key Takeaways
- Salesforce stores data using objects and relationships.
- SOQL is used to retrieve Salesforce data.
- Trigger logic should be kept inside a handler class.
- LWCs provide reusable and interactive user interfaces.
